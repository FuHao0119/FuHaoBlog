# 搞定 Fedora 43 + Niri 中 XWayland 应用输入法字体过小的问题

如果你在 Fedora 43 上搭配 Niri 作为 Wayland 合成器，可能会遇到一个烦人的小问题：在某些 XWayland 应用（比如 QQ、微信这类）里，输入法候选框的字体小得跟蚂蚁一样，看着特别费劲。这个问题通常是 XWayland 应用的 DPI 缩放不正确导致的。别担心，这篇指南会手把手教你如何解决它！

## 你需要…

*   一台装着 Fedora 43 的电脑
*   正在使用 Niri 作为 Wayland 合成器
*   正被 XWayland 应用（如 QQ、微信）输入法字体太小的问题所困扰

## 修复“蚊子腿”字体的步骤

### 第一步：安装 `xrdb` 工具

首先，我们得确保系统里装了 `xrdb`。这是一个用来管理 X 服务资源数据库的工具，我们可以用它来设置 XWayland 应用的 DPI 这类属性。

```bash
sudo dnf install xrdb
```

### 第二步：计算你自己的 DPI 值

接下来，你需要根据你的显示器缩放比例来计算出正确的 DPI 值。公式很简单：`96 × 你的缩放比例`。

举几个栗子：
*   如果你的缩放是 125%：`96 × 1.25 = 120`
*   如果你的缩放是 150%：`96 × 1.5 = 144`
*   如果你的缩放是 200%：`96 × 2 = 192`

根据你系统的显示设置，选择对应的 DPI 值。在这篇教程里，我们以 `144`（也就是 150% 缩放）为例。

### 第三步：创建或编辑 `.Xresources` 文件，让设置永久生效

为了让 DPI 设置永久生效，你需要在你的主目录下创建一个叫 `.Xresources` 的隐藏文件（如果已经有了就编辑它）。X 应用在启动时会自动读取这个文件。

用 `nano` 或者你喜欢的任何文本编辑器打开它：

```bash
nano ~/.Xresources
```

在编辑器里，加上下面这行，记得把 `144` 换成你上一步算出来的值：

```
Xft.dpi: 144
```

*   按 `Ctrl + O` 保存文件。
*   按 `Enter` 确认文件名。
*   按 `Ctrl + X` 退出编辑器。

### 第四步：让 Niri 在启动时加载 `.Xresources` 配置

Niri 本身不会自动加载 `.Xresources` 文件，所以我们得告诉它在启动时加载一下。

打开你的 Niri 配置文件，老地方 `~/.config/niri/config.kdl`：

```bash
nano ~/.config/niri/config.kdl
```

找到 `spawn-at-startup` 的部分，加上下面这行：

```kdl
spawn-at-startup "xrdb" "-merge" ".Xresources"
```

保存并退出 Niri 配置文件。

### 第五步：立即应用设置并重启应用

好消息是，你不需要重启整个电脑！你可以先在终端里手动运行 `xrdb` 命令，然后只要重启一下出问题的 XWayland 应用（比如 QQ 或微信）就行了。

```bash
xrdb -merge ~/.Xresources
```

运行完这条命令，再重新打开你的应用，怎么样，输入法的字体是不是已经变得清晰可读了？

终于可以和“蚊子腿”小字体说拜拜了！享受在 Niri 上更舒适的 XWayland 应用输入体验吧！
